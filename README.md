# DESAFIO-QA-BEEDOO-2026
Qual você acredita ser o objetivo da aplicação?

Como pode-se observar o objetivo da aplicação é o cadastro, listagem e atualização nas informações de diversos cursos. 
Contendo diferentes modelos como presencial e online, além de informações sobre vagas, instrutores e datas de curso.

Quais são os principais fluxos disponíveis

1°Fluxo: Listagem de cursos disponíveis 
2°Fluxo: Cadastro de novos cursos

Quais pontos do sistema você considera mais críticos para teste?

Cadastro de novos cursos e atualizações em cursos já existentes, além de atualizações em tempo real para candidatos se manterem informados.

Maiores informações sobre os cursos já disponíveis.
